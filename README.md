Supply Chain Analysis Dashboard | Chain IQ

Project Overview

This project analyzes supply chain performance using Microsoft Excel.
The dashboard presents key indicators and comparisons related to
revenue, profit, stock availability, inventory levels, and supplier
delays.

Project Objectives

• Compare performance between the first and second halves of 2024.
• Review revenue and profit across the periods shown in the dashboard.
• Monitor stock-out and overstock indicators.
• Compare average supplier delays.
• Present key metrics in an interactive, easy-to-read dashboard.

Tools & Skills

• Microsoft Excel
• Pivot Tables
• KPI Analysis
• Data Visualization
• Dashboard Design

Business Value

This dashboard can help stakeholders spot changes in performance,
monitor inventory indicators, and identify suppliers whose delays may
deserve further investigation. Any recommendations should be based on
validation of the underlying data and KPI definitions.
